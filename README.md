# Java Back-end – Estudos e Projetos

Repositório dedicado a estudos e projetos em **Java Back-end**, com foco em lógica de programação, orientação a objetos e integração com banco de dados.

##  Objetivo
Consolidar conhecimentos em Java e tecnologias relacionadas, aplicando conceitos fundamentais no desenvolvimento de sistemas e aplicações back-end.

##  Tecnologias Utilizadas
- **Java**
- **NetBeans**
- **MySQL**
- **SQL**
- **Git / GitHub**

##  Conceitos Trabalhados
- Programação Orientada a Objetos (POO)
- Estruturas de dados e coleções
- Integração Java com Banco de Dados (JDBC)
- CRUD (Create, Read, Update, Delete)
- Organização e boas práticas de código

##  Estrutura do Repositório
- Projetos Java desenvolvidos no NetBeans e/ou IntelliJ  
- Códigos organizados por funcionalidades  
- Exemplos práticos voltados para back-end  

##  Em Evolução
Este repositório está em constante atualização conforme avanço nos estudos e desenvolvimento de novos projetos.
